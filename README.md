# HR Analytics Portfolio – Employee Attrition Analysis

## 📌 Project Overview
This project is an end-to-end HR analytics solution built using SQL, Power BI, and Tableau. The objective is to analyze employee data and identify patterns related to attrition, workforce distribution, and job satisfaction.

---

## 🛠 Tools Used
- SQL (MySQL)
- Power BI
- Tableau
- Excel

---

## 📊 Key KPIs
- Total Employees
- Active Employees
- Attrition Rate
- Average Age
- Department-wise Attrition
- Gender-wise Attrition
- Job Satisfaction Analysis
